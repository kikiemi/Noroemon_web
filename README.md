# 黙々ノロえもん

ピッチとテンポを独立して変えられる、ブラウザ完結型の音楽プレイヤー。

## 機能

- ピッチ ±24半音 / テンポ 25〜400% を独立変換
- フォルマント補正、逆再生、ボーカルキャンセル
- 10バンドEQ、リバーブ、ビットクラッシャー、モジュレーション、コンプレッサー
- A-Bループ、1曲 / 全曲ループ、シャッフル
- BPM自動検出、リアルタイムピッチ表示
- 複数プレイリスト（IndexedDB + OPFS）
- 現在の設定を反映した WAV 書き出し
- マイク入力、ライト / ダーク / 自動テーマ、PWA対応

## 使い方

`node_modules/` を除いた一式を静的ホスティングに配置するだけで動作します（Apache 用の `.htaccess` を同梱）。

ソースから再ビルドする場合:

```
npm install
npm run build
```
