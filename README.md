# Noroemon Web (のろえもん Web)

> **「先生、この曲速すぎて何弾いてるか分かりません！」**  
> **「なら、遅くすればいいじゃない（音程はそのままで）。ついでにパート別にバラバラにしておいたよ。」**

**Noroemon Web** は、ブラウザ上で完結する高機能オーディオ解析・耳コピ・練習支援Webアプリケーションです。

かつて多くの楽器練習者や耳コピ勢を救った伝説のツールへのリスペクトを込めつつ、ブラウザ・WEBの世界へ旅立ちました。「ただ再生速度を変えるだけのツール」にとどまらず、**AIによる6パート音源分離**や**本格的なリアルタイムDSPエフェクト**までをブラウザ1つで実現する、令和のオーディオ解剖室です。

---

## 主な機能

### 1. 音程を保持した高品質タイムストレッチ＆ピッチシフト (`pv_worklet.js`)
再生速度を変えても音程が崩れない、独自の **Phase Vocoder (フェーズボコーダ)** を `AudioWorklet` 上でリアルタイム駆動。
- **スピード変更**: 原曲のキーを維持したまま、超スロー再生から倍速再生まで自由自在。速弾きフレーズの耳コピに。
- **ピッチ変更**: 再生速度はそのまま、半音単位・セント単位でのキー変更が可能。半音下げチューニング曲の練習やキー調整に最適です。

### 2. ブラウザ内完結のAI・6ステム音源分離 (`htdemucs_6s`)
内蔵のAIモデル（**HTDemucs 6-stem**）により、楽曲を6つのパートへ高精度に分離します。
- 🎤 **Vocals** (ボーカル)
- 🥁 **Drums** (ドラム)
- 🎸 **Bass** (ベース)
- 🎸 **Guitar** (ギター)
- 🎹 **Piano** (ピアノ)
- 🎻 **Other** (その他シンセ・ストリングス等)

> 💡 **完全クライアントサイド実行**: 外部サーバーに音声データをアップロードすることなく、ブラウザ内（ローカル）で推論・分離を行います。通信容量とプライバシーの面でも安心です。

### 3. 職人仕様のリアルタイムDSP＆エフェクト群 (`fx_worklets.js` / `dsp.js`)
AudioWorkletによる低遅延な信号処理を搭載。
- **ボーカルキャンセリング / センター抽出**: 位相処理による手軽な定位加工。
- **各種フィルタ・EQ**: ベースの低域やシンバルの高域など、聴き取りたい帯域を狙い撃ちして強調・カット。

### 4. 視覚で捉える波形描画＆自動解析 (`waveform.js` / `visualizer.js` / `bpm_worker.js`)
- **高精度波形表示**: 全体波形と拡大表示、区間反復が可能な **A-Bリピート機能** を完備。
- **リアルタイム・スペクトラムアナライザ**: 自前実装のFFTワーカー（`fft.js` / `ana.js`）により周波数分布を滑らかに可視化。
- **自動BPM検出**: バックグラウンドのWeb Worker（`bpm_worker.js`）が曲のテンポを自動解析。

### 5. PWA対応 ＆ ローカル保存・WAV書き出し (`store/db.js` / `wav.js`)
- **IndexedDB によるデータ永続化**: 読み込んだ楽曲や解析データ、プレイリストはブラウザ内に自動保存。
- **PWA (Progressive Web App) 対応**: デスクトップやスマートフォンにアプリとしてインストール可能。
- **WAVエクスポート**: ピッチ・スピードを変更した音声や、分離した各パートをそのままWAVファイルとして保存可能。

## 使い方

1. **ファイルを読み込む**: お手持ちのオーディオファイル（MP3, WAV, FLAC, OGG等）を画面にドラッグ＆ドロップ。
2. **コントロール**: 再生速度やピッチを調整、またはA-Bループを設定して練習したい箇所を反復再生。
3. **パート分離**: 必要に応じてAI音源分離を実行し、聴き取りたい楽器をソロ/ミュート。
4. **書き出し**: 調整した音源や分離トラックをWAVファイルとしてダウンロード。

## ローカル環境での起動方法

`AudioWorklet` や `Web Worker`、`ONNX` モデル読み込みを行うため、ローカルサーバー経由でアクセスしてください。

```bash
# リポジトリのクローン
git clone https://github.com/kikiemi/Noroemon_web.git
cd Noroemon_web

# Pythonでローカルサーバーを起動する場合
python -m http.server 8080

# Node.js (npx) でローカルサーバーを起動する場合
npx serve .
```

起動後、ブラウザで `http://localhost:8080` を開きます。  
※ `SharedArrayBuffer` 等のマルチスレッド機能をフル活用する場合、COOP (`Cross-Origin-Opener-Policy`) / COEP (`Cross-Origin-Embedder-Policy`) ヘッダーを有効化したサーバー環境を推奨します。

---

## 注意事項

- **AI音源分離の初回読み込み**: モデルデータ（`htdemucs_6s.onnx`）のダウンロードおよびブラウザ内での初期化に少々時間がかかる場合があります。
- **推奨環境**: メモリ容量とCPU/GPUスペックに余裕のあるモダンブラウザ（Chrome / Edge 等）での利用を推奨します。
