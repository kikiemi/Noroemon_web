# 黙々ノロえもん

ピッチとテンポを独立して変えられる、ブラウザ完結型の音楽プレイヤー。AIによる楽器ごとの音源分離と、耳コピ・楽器練習向けの機能（聞々ハヤえもん風）を備えています。

## 機能

### 再生・変換
- ピッチ ±24半音（Shift+ドラッグ / 直接入力で0.01半音単位）/ テンポ 10〜400% / 再生周波数 25〜400%（テープのように音程と速さが一緒に変わる）
- 位相ボコーダは「Phase Vocoder Done Right」方式（強い成分から位相を伝える）、ステレオはM/S処理で定位を保持、打音の立ち上がりで位相を合わせ直してアタックのにじみを抑制
- フォルマント補正は「True Envelope」推定（声の高さに合わせて平滑化の細かさを自動調整）をボコーダ内で実行
- 音程変更時の補間は64タップのカイザー窓sinc（原音のままのときは無補間・無変換）
- 逆再生（データを書き換えずに読む向きだけ反転）、ボーカルキャンセル（低音は残す）

### エフェクト
- 10バンドEQ（プリセットに低音/中音/高音の強調・カット、電話の声）
- リバーブ（ホール / 部屋 / プレート / 大聖堂 / 洞窟）、ビットクラッシャー
- モジュレーション（フランジャー / コーラス / フェイザー / トレモロ）、コンプレッサー（ソフトニー）
- ディレイ / エコー（短い〜長いエコー、ステレオ、山びこ、ダブリング、ダブルキック）
- ディストーション（折り返しを抑えるADAA処理）
- チャンネル（モノラル / 左のみ / 右のみ / 左右入れ替え）、パン、ステレオ幅
- ノーマライズ（EBU R128 / -14 LUFS）、先読みリミッター（音割れ防止・普段は無色透明）
- 設定のプリセット保存、一括リセット

### AI音源分離
- Demucs v4（htdemucs_6s）で ボーカル / ドラム / ベース / ギター / ピアノ / その他 の6パートに分離
- 各パートの音量・ミュート・ソロをリアルタイムに変更、ステムごとのWAV書き出し
- WebGPU対応環境ではGPU、それ以外はCPU（マルチスレッド）で計算。初回にモデル（約130MB）を取得して端末に保存し、以後はオフラインでも使えます
- 分離結果は曲ごとに端末へ保存され、次回は計算なしで読み込みます

### 練習（聞々ハヤえもんの機能を参考に再実装）
- A-Bループ（波形ドラッグ、または `[` `]` キーで現在位置をA/Bに）、マーカー（`M`で追加、右クリックで削除）とマーカー間ループ
- ループ回数の指定、1周ごとにテンポを上げ下げ（目標テンポで停止）
- 曲の拍に合わせたクリック音（BPM自動検出の拍位置を使用）
- 特殊再生：古びたレコード / 電池切れ / 歌へたモード / ベースの耳コピ / ハイハットの耳コピ / 聴覚トレーニング
- 停止時のフェードアウト、スリープタイマー、前回の再生位置から再開

### その他
- BPM・キー（調）の自動検出。ピッチ・テンポ変更後の値を表示
- 複数プレイリスト（IndexedDB + OPFS）、ファイル・フォルダのドラッグ＆ドロップ、動画ファイルの音声も読み込み可
- WAV書き出し（16bit ディザあり / 24bit / 32bit float）。A-B区間だけの書き出しにも対応
- マイク入力、ライト / ダーク / 自動テーマ、PWA対応（ホーム画面に追加できます）、キーボード操作（設定画面に一覧）

## 使い方

`node_modules/` と `tools/` を除いた一式（`dist/` `vendor/` `models/` を含む）を静的ホスティングに配置するだけで動作します。Apache 用の `.htaccess` を同梱しています。

AI分離を速くするには、サーバーで次のヘッダーを付けてください（`.htaccess` には設定済み）。付けられない場合も、2回目以降の表示ではサービスワーカーが同じ効果を与えます。

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

ソースから再ビルドする場合:

```
npm install
npm run vendor
npm run build
```

## AIモデルについて

`models/` には Meta の [Demucs](https://github.com/facebookresearch/demucs)（MITライセンス）の htdemucs_6s を ONNX 形式に変換したものが、GitHub の容量制限に収まるよう 40MB ずつに分割して入っています。作り直す・別のモデル（4パートの htdemucs など）にする場合は、Python に `torch` `onnx` `onnxruntime` `demucs` を入れて次を実行します。

```
python tools/export_demucs_onnx.py --name htdemucs_6s --out models
```

変換時に PyTorch 版の出力と照合し、誤差を表示します。設定画面の「モデルファイルを選ぶ」から手元の `.onnx` を使うこともできます。
